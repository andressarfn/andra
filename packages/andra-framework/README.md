# andra-framework

> **Status: Pre-Alpha — not yet implemented.**

`andra-framework` is the opinionated framework layer of the **Andra** ecosystem. It is built on top of [`andra-core`](../andra-core/README.md) and will provide higher-level abstractions, conventions, and integrations for building production-ready LLM-powered corporate chatbots.

---

## Relationship to andra-core

| Package | Role |
|---|---|
| `andra-core` | Framework-agnostic building blocks (contracts, pipeline, models) |
| `andra-framework` | Opinionated layer — conventions, wiring, integrations built on core |

---

## Installation

> Not yet available on PyPI.

```bash
# From the monorepo (development)
cd packages/andra-framework
poetry install
```
